gsite 项目手动启动流程

光何快速开发平台（Spring Boot 2.7.18 / JDK 8 多模块）｜后端服务 + 接口文档｜整理 2026-08-28，2026-08-29 修订（my.ini 已修正，MySQL 改为 start.bat 启动）

启动顺序固定为：① MySQL → ② Redis → ③ 后端。全部命令在 cmd（命令提示符） 中执行；每一步各开一个窗口，窗口不要关（关闭窗口即停止该服务）。

① 启动 MySQL

方式一（推荐）：双击 D:\devTools\mysql\start.bat。
方式二：命令行启动，效果相同（同目录 my.ini 生效）：

cd /d D:\devTools\mysql
bin\mysqld.exe --console

窗口光标停住、无报错即为成功。验证（新开窗口）：
"D:\devTools\mysql\bin\mysqladmin.exe" -h 127.0.0.1 -uroot -proot ping 返回 mysqld is alive。

my.ini 中 basedir / datadir 已修正为 D:\\devTools\\mysql 与 D:\\devTools\\mysql\\data（2026-08-29），所以无需再手工指定路径。若将来 my.ini 被改坏，可用下面命令兜底启动：

"D:\devTools\mysql\bin\mysqld.exe" --no-defaults ^
  --basedir="D:\devTools\mysql" ^
  --datadir="D:\devTools\mysql\data" ^
  --port=3306 --character-set-server=utf8mb4

② 启动 Redis

cd /d D:\devTools\redis
redis-server.exe redis.windows.conf

验证（新开窗口）：D:\devTools\redis\redis-cli.exe ping 返回 PONG。

可选：执行 install.bat 可把 Redis 注册为 Windows 服务，开机自启。

③ 启动后端服务

cd /d D:\workspace\lab\gsite
"D:\devTools\jdk\jdk1.8.0_202\bin\java.exe" -jar ^
  guanghe-server\target\guanghe-server.jar ^
  --spring.profiles.active=local

启动约 12 秒，日志出现下列两行即成功：

Tomcat started on port(s): 48080 (http) with context path ''
Started GuangheServerApplication in 11.2 seconds

--spring.profiles.active=local 可省略（application.yaml 中默认已是 local）；显式写出更保险。

④ 只有 jar 不存在时才需要打包

cd /d D:\workspace\lab\gsite
set JAVA_HOME=D:\devTools\jdk\jdk1.8.0_202
D:\devTools\maven\bin\mvn.bat -B -T1C clean install -DskipTests

产物：guanghe-server\target\guanghe-server.jar。根 pom 默认只启用精简版模块（framework + server + module-system + module-infra），其余模块在 pom.xml 中以注释形式保留，按需取消注释后重新打包。

⑤ 首次建库（只需做一次）

cd /d D:\workspace\lab\gsite

"D:\devTools\mysql\bin\mysql.exe" -h 127.0.0.1 -uroot -proot ^
  -e "CREATE DATABASE IF NOT EXISTS gsite DEFAULT CHARACTER SET utf8mb4;"

"D:\devTools\mysql\bin\mysql.exe" -h 127.0.0.1 -uroot -proot gsite ^
  < sql\mysql\gsite.sql

"D:\devTools\mysql\bin\mysql.exe" -h 127.0.0.1 -uroot -proot gsite ^
  < sql\mysql\quartz.sql

导入后 gsite 库共 59 张表（48 业务表 + 11 张 Quartz 表），其中演示表名为 guanghe_demo01_contact 等。其余数据库方言脚本在 sql\oracle、sql\postgresql、sql\dm 等目录下。

⑧ 停止服务

  • 后端 / Redis：直接关闭对应 cmd 窗口，或按 Ctrl+C。
  • MySQL 建议优雅关闭（避免下次启动做崩溃恢复）： 
    "D:\devTools\mysql\bin\mysqladmin.exe" -h 127.0.0.1 -uroot -proot shutdown

⑨ 注意事项

  • profile 选择：application-dev.yaml 原先指向上游公网 Redis，现已改为本机 127.0.0.1，dev 与 local 都连本机 MySQL/Redis；本机开发仍用默认的 local 即可。
  • 安全：local 配置开启了接口 Mock（guanghe.security.mock-enable: true），带请求头 Authorization: Bearer test<用户ID> 可绕过密码；且 Druid 监控台未设账号密码。此机器不要直接暴露公网，对外部署前必须关闭 Mock 并加口令。
  • Redis 版本：当前 3.0.504 可正常运行，但项目文档建议 Redis 5.0 及以上。
  • 数据源：local 的主/从库都指向本机 gsite（从库为模拟，懒加载）；换库请改 guanghe-server\src\main\resources\application-local.yaml 后重新打包。
  • MySQL 字符集：my.ini 中 character-set-server=utf8 在 MySQL 8 里等价于 3 字节的 utf8mb3。实测现有 gsite 库与 59 张表都显式声明了 utf8mb4（table_collation 全为 utf8mb4_unicode_ci），不受影响；但今后新建库/表若不显式写字符集，emoji 等 4 字节字符会存不下。建议把该行改为 character-set-server=utf8mb4 并补一行 collation-server=utf8mb4_unicode_ci（改完需重启 MySQL）。
